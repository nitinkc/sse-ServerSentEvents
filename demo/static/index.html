THE BROWSER SIDE

A few lines. A live connection.

const stream = new EventSource(
  "/events?channels=clock"
);
stream.addEventListener("tick", (event) => {
  const data = JSON.parse(event.data);
  clock.textContent = data.time;
});

Try Disconnect above. The clock freezes. Connect starts a new stream.

THE TAKEAWAY

No need to keep asking.

Unlike polling, the browser does not repeatedly request a new price. The server sends a stock event when a price changes.

Different event names can share one stream. The browser chooses which listener handles each update.

    Two tabs. One shared stream of messages.

    1. Open this page in a second browser tab.
